= 1. Establish the fleet baseline (10 minutes)

Inspect the contract and create three node-scoped REHEARSAL evidence records. Confirm that every node names the same workload identity, policy bundle, reference-values version, freshness window, and correlation identifier.

Run the baseline. `QUALIFIED_REHEARSAL` means only that the deterministic control path is coherent. Record that live guests, quotes, resource release, and model execution all remain zero.
