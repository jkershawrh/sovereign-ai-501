= 8. Human review and cleanup (15 minutes)

== Show

The fleet review package is participant-owned. The qualifier, presentation,
Service, NetworkPolicies, Showroom, and namespace are Launchpad-owned. A learner
must not delete shared platform resources to manufacture a zero-residue claim.

== Learn

Human review can request independent certification; it cannot turn rehearsal
fixtures into current TDX evidence. Participant cleanup and Launchpad reclaim
are separate proof boundaries.

== Do

Record the bounded human disposition, then remove only participant-owned files.

[source,bash,role="execute"]
----
python3 - "$FLEET_DIR/human-disposition.json" <<'PY'
import json, pathlib, sys
d={"owner":"northstar-fleet-review","decision":"request-independent-live-certification","mayPromote":False,
   "blockers":["current Intel TDX quotes","live confidential guests","reviewed Trustee verifier and KBS","protected-resource release","model execution","measured capacity"]}
pathlib.Path(sys.argv[1]).write_text(json.dumps(d,indent=2)+"\n")
print(json.dumps(d,indent=2))
PY
rm -rf -- "$FLEET_DIR"
----

== Prove

Require zero participant residue while the Launchpad-owned seat remains healthy
for other workshop participants.

[source,bash,role="execute"]
----
test ! -e "$HOME/sovereign-ai-501"
test "$(oc get deploy sovereign-ai-501-qualifier -o jsonpath='{.status.readyReplicas}')" -ge 1
curl -fsS "$FLEET_URL/healthz" | python3 -m json.tool
echo "PASS: participant-owned residue is zero; Launchpad-owned lifecycle remains intact"
----

When the order is reclaimed, Launchpad must independently prove the namespace,
Routes, RoleBindings, entitlements, and catalog resources reach zero. Until a
live confidential fleet supplies current hardware-rooted evidence and all
destination gates pass, stop here: do not certify, promote, or publish.
